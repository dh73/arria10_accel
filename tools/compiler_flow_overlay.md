# Isolated flow initialization overlay

```sh
python3 tools/compiler_flow_overlay.py /path/to/original/modules /new/overlay
```

Generates two source-pinned modules. Missing IPA flow selection is resolved from
the model's own `defaultname` query before flow-qualified queries are issued.
Explicit flows and non-IPA flow initialization remain unchanged. Nonzero child
exit status or signal termination fails the query instead of returning output
as a successful value. Existing textual error handling remains in place.

Both original and resulting full-file hashes must match the qualified pair.
There is no hash override, fuzzy patching, in-place update or installation step.
The output directory must be new and outside the input tree. Bind the generated
files into an isolated qualification environment; retain the original modules.

The generated bytes match the overlay qualified by native hardware-object and
RTL early-link compilation and source-bound helper tests. This does not qualify
a BSP, physical device geometry, full hardware linking or bandwidth. Memory-port
configuration and the generated completion-counter correction remain separate.
